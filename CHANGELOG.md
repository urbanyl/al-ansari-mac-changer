# Changelog

## 1.0.0 — 2026-10-29

First public release of **Al-Ansari MAC Changer**.

### Added

- MAC address editor with locally administered, universal and vendor OUI modes.
- 40 vendor prefixes and generation of up to 100 candidate addresses.
- Apply to selected adapter, apply to all adapters, shuffle all adapters.
- System identity: computer name, NetBIOS, workgroup, MachineGuid.
- Five identity profiles with a preview panel.
- DNS resolver presets (12 providers) with per-adapter backup and restore.
- IPv6 temporary addresses and advertising ID controls.
- Automatic backup store, change journal and report export.
- Splash screen with the Basmala, tray icon and background mode.
- Classic Win32-style English UI, no Electron and no external UI framework.
